# Using Common Resources

As we saw earlier, when designing a form in RPA Connect, you can add static images and spaces for attachments. However, there are many instances where you’ll need to use the same material repeatedly, such as client logos that remain unchanged in the header or downloadable files common to all users of a specific form.

Below, you will learn how to use the integrated resource repository in the RPA Connect Build tool to simplify this task.
