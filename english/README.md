# Quick Start

In this section, we will cover the basic aspects of how RPA Connect works. By the time you complete the Quick Start, you will have the knowledge to:

* Log in to RPA Connect using different access options.
* Create, edit, and delete a form.
* Navigate the RPA Connect workspace.
* Design a basic form.
