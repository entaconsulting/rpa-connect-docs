# Advanced Options

The _**Options**_ tab offers a series of advanced settings that affect the user experience when interacting with the form. The main options are:

* _**titleTemplate:**_ defines the form's title, either as a fixed text or dynamic text based on the data entered by the user in a field. This is the title that will be displayed when managing the form on the Submissions screen in the Portal or the Teams app.
* _**tagTemplates:**_ allow you to configure values based on the form fields, which can then be used to filter or sort submissions according to the responses obtained.
* _**confirmationMessage:**_ sets the message automatically displayed to the end user to confirm that their response has been successfully received.
* _**fullWidthForm:**_ determines the use of screen space, which can be set to true (_**true**_) to force full width, or false (_**null**_) to adjust to the default form width, leaving margins on both sides.
