# Admin App

In this section, we will leave the _**Build**_ tool we have explored so far to dive into _**Admin**_ and learn about all the options it offers for greater control over your environment's forms and their access permissions. By the end of this section, you will be able to:

* Distinguish the types of users and groups in RPA Connect and their characteristics.
* Add and remove new users and groups.
* Assign, modify, and revoke permissions and roles.
* Understand how API Keys work and configure them.
